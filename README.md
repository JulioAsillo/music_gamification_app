# MusiQuest

App de música local con gamificación y tracking.

**Versión:** 1.0.0  
**Plataforma:** Android 5.0+

## 🚀 Instalación

```bash
flutter pub get
flutter run
```

## 📦 Compilar APK

```bash
flutter build apk --release --split-per-abi
```

APKs optimizados en: `build/app/outputs/flutter-apk/`
